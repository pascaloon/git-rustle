Performance is the product

Built for speed, not for show.

Every layer is designed around one rule: the UI thread never waits. Git Rustle is engineered to feel instant on repositories with hundreds of thousands of commits.

Virtualized everything

History, branches, changed files and diff lines only construct the rows you can see. Scroll a million-line diff like it is ten.

GPU-painted graph

Graph lanes, diff selections and intraline highlights are drawn directly by DirectX through GPUI — no DOM, no layout thrash.

Background workers

Repository loading, status, search, diffs, stats, network and commit details run off the UI thread. Results stream in as they land.

Persistent caches

Packed history, lazy message/path search indexes and immutable remote metadata are reused across launches. Second open is faster than the first.

Zero idle redraws

An idle window costs nothing. Frames are only produced when something changes, so Git Rustle stays out of your GPU and battery budget.

Instant startup

Repository loading and layout overlap DirectX initialization. The first history frame appears while the window is still fading in.

Compiled for the metal

Release binaries are built with fat link-time optimization and a single code-generation unit, powered by Gitoxide for pure-Rust repository access and GPUI for the renderer. Performance regressions are measured against a preserved baseline executable before every notable change. 

# Cargo.toml
[profile.release]
opt-level     = 3
lto           = "fat"
codegen-units = 1
panic         = "abort"

Everything you reach for

A complete client. Nothing bolted on.

Commit graph & inspector

Resizable lane graph with branch, tag and remote badges. Click a row for the full message, author, committer, dates, parents and hash.

Side-by-side diffs

Intraline highlights, word wrap, horizontal panning and line-accurate copying. Syntax colors for Rust, C/C++, C#, JS/TS, Python, Go, Java, Ruby, shell, HTML/CSS, JSON, TOML, YAML, SQL and Markdown.

Search that streams

Type to filter history as indexes build. Scope with prefixes: f:a:m:s: for paths, authors, messages and hashes.

Remote previews

Browse GitHub and GitLab branches, tags and missing commits through read-only APIs. Ghost previews never fetch objects or touch your refs.

Interactive rebase

Reorder, reword, squash, fixup, edit and drop from an editable plan. Conflicts guide you through compare, edit, stage, continue, skip or abort.

Undo / redo history

Commits and checkouts record recoverable states. Double-click to move backward or forward. Nothing is force-reset or auto-stashed behind your back.

Pending changes composer

Pick files and folders with checkboxes, write a multiline message and optionally branch off in one step. Drafts survive browsing diffs.

Safe in-app updates

Updates come straight from public GitHub Releases, verified against pinned SHA-256 digests, and restart with your draft intact.

Free & open source

Free. Open. Yours.

Git Rustle is free software under the GNU GPL-3.0. No license keys, no subscriptions, no accounts, no telemetry. The whole client is on GitHub for you to read, audit, fork and improve.

Free forever

Download and use it on every machine you own. There is no paid tier, trial period or sign-up form — just a single portable executable.

Open source, GPL-3.0

Every line is public. Read how diffs are computed, audit how tokens are stored, or fork it and make it yours. Copyleft keeps it that way.

Transparent updates

The in-app updater pulls from the public GitHub Releases feed over HTTPS and verifies SHA-256 digests. Checksums ship next to every build.

v0.1.2 · git-rustle-x86_64-pc-windows-msvc.exe · All releases

Windows only. Git Rustle renders with DirectX and integrates with Windows Credential Manager, Explorer and Windows Terminal; other platforms are not supported.

Requirements

  • Windows 10 or 11, x64
  • A DirectX-capable graphics driver
  • Git for Windows on PATH for commits, checkouts and recovery
  • Windows Terminal (optional) for the terminal launcher

Build from source

PS> git clone https://github.com/pascaloon/git-rustle.git
PS> cd git-rustle
PS> cargo build --release --locked
PS> .\target\release\git-rustle.exe [PATH]

Requires a stable Rust MSVC toolchain and Visual Studio C++ Build Tools.
